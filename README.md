# 🤖 Интеллектуальный AI-агент технической поддержки 1С (АО «Молвест»)

Интеллектуальная система автоматизации технической поддержки пользователей 1С на базе больших языковых моделей (**GigaChat API**) и технологии **RAG** (Retrieval-Augmented Generation). Проект разработан для снижения нагрузки на операторов первой линии, ускорения ответа до 5 секунд и работы со скриншотами интерфейсов 1С.

---

## 🚀 Основные возможности
1. **Режим «Вопрос-ответ» (Чат-бот):** Анализ текстовых запросов пользователей и поиск точных ответов по централизованной базе знаний.
2. **Анализ скриншотов (Computer Vision):** Распознавание текста и визуальной информации с экранов ошибок 1С через мультимодальный GigaChat.
3. **Автоматическая эскалация:** Если уверенность нейросети ниже порога или ответа нет в базе знаний, система переводит диалог на живого оператора.
4. **Панель администратора (Streamlit):** Управление базой знаний в один клик (поддержкаформатов `.docx`, `.pdf`, `.md`, `.html`) и встроенный дашборд метрик эффективности.
5. **REST API (FastAPI):** Готовый бэкенд для интеграции с корпоративными мессенджерами (Bitrix24, Redmine HelpDesk) и режим «Суфлер».

---

## 🛠 Стек технологий
* **Язык программирования:** Python 3.10+
* **LLM / Vision:** GigaChat API (Сбер)
* **Веб-интерфейс / Админка:** Streamlit
* **REST API:** FastAPI, Uvicorn
* **Векторная база данных:** ChromaDB
* **Эмбеддинги:** HuggingFace (`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`)

## 🕹 Руководство пользователя: Что делают кнопки и элементы интерфейса

После запуска команды `streamlit run app.py` в браузере откроется панель управления, состоящая из трех вкладок и бокового меню:

### ⚙️ Боковая панель (Настройки)
* **Поле "Токен GigaChat API":** Сюда вводится твой персональный ключ доступа. Без него система заблокирована в целях безопасности.

### 💬 Вкладка 1: «Чат-бот»
* **Поле ввода текста ("Опишите проблему..."):** Основное поле для отправки текстовых запросов или вопросов по работе в 1С.
* **Кнопка прикрепления файла (Скриншот):** Позволяет загрузить изображение (`.png`, `.jpg`) с ошибкой интерфейса 1С для последующего анализа нейросетью.

### 📚 Вкладка 2: «Управление Базой»
* **Кнопка "🗑️ Очистить базу знаний и сбросить данные":** Полностью стирает локальную векторную базу данных (`chroma_db`), очищает историю текущего чата и обнуляет графики в аналитике для тестирования с чистого листа.
* **Загрузчик файлов (PDF, DOCX, MD, HTML):** Позволяет перетащить или выбрать новый документ с регламентами. После загрузки текст автоматически разбивается на фрагменты (хунки), векторизуется и добавляется в память агента.

### 📊 Вкладка 3: «Аналитика»
* **Метрики эффективности:** Отображают ключевые показатели работы службы поддержки (доля автоматизированных запросов, среднее время ответа в секундах, процент эскалаций).
* **Динамический график:** Наглядно показывает распределение обращений по категориям (ошибки входа, закрытие месяца, справочники и т.д.). Обнуляется при очистке базы.
